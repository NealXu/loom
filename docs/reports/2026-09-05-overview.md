## 关键缺口

1. **无 daemon/服务启动** — `create_app` 未接 `loom serve`；hooks/inbox/cron 写入 events 但无常驻循环消费
2. **门禁非交互** — CLI/Web 无 approve/reject 入口，`_run_instance` 对 `gate=approve` 自动放行
3. **无 tier 路由** — `router.py` + `loom.toml` 均未实现；`tier` 仅元数据
4. **预算未硬执行** — `budget_tokens` 存而不拦；`cost_usd` 累计未贯通到 $5 晨报红线
5. **适配器无超时** — `proc.communicate()` 无 `wait_for`，挂起 CLI 永久阻塞
6. **Store API 不全** — edge/artifact/event 无 CRUD 方法，8+ 处裸 SQL
7. **未建模板** — `content-pipeline.yaml`、`ops-deploy.yaml`
